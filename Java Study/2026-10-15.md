## 1. 연산자 (Operator)

연산자는 데이터를 계산하거나 비교하고, 조건에 따라 프로그램을 실행할 때 사용하는 기호이다.

1-1. 부정 연산자

! : 논리값을 반전한다.

표현식	결과
!true	false
!false	true
boolean flag = true;

System.out.println(!flag); // false

1-2. 비교 연산자

두 값을 비교하여 true 또는 false를 반환한다.

연산자	의미	예시	결과
==	같다	10 == 10	true
!=	같지 않다	10 != 10	false
<	작다	10 < 20	true
>	크다	10 > 20	false
<=	작거나 같다	10 <= 10	true
>=	크거나 같다	10 >= 10	true
숫자형: byte, short, int, long, float, double
char: 문자 코드 값을 기준으로 비교할 수 있다.
boolean: ==, !=로 비교할 수 있다.
String: 문자열 내용 비교에는 equals()를 사용한다.
int a = 10;
int b = 20;

System.out.println(a < b);  // true
System.out.println(a == b); // false

String s1 = "Java";
String s2 = "Java";

System.out.println(s1.equals(s2)); // true

주의: 문자열의 내용 비교에는 ==보다 equals()를 사용하는 것이 일반적이다. ==는 참조값을 비교한다.

1-3. 논리 연산자

여러 조건을 조합할 때 사용한다.

연산자	의미	설명
&&	AND	모든 조건이 참이면 true
`		`
!	NOT	논리값을 반전
int num = 10;

System.out.println(num >= 0 && num <= 20); // true
System.out.println(num < 0 || num > 20);   // false

1-4. 대입 연산자

변수에 값을 저장하거나 연산 결과를 대입한다.

int num = 10;

num += 5;  // num = num + 5
num -= 3;  // num = num - 3
num *= 2;  // num = num * 2
num /= 2;  // num = num / 2
num %= 3;  // num = num % 3


=는 대입 연산자이며, ==는 두 값이 같은지 비교하는 연산자이다.

1-5. 삼항 연산자

조건에 따라 서로 다른 값을 선택하는 연산자이다.

형식

조건식 ? 참일 때의 값 : 거짓일 때의 값;


예제: 짝수와 홀수 판별

int num = 10;

String result = num % 2 == 0 ? "짝수" : "홀수";

System.out.println(result); // 짝수


삼항 연산자는 간단한 조건식에서 유용하며, 복잡한 조건은 if~else를 사용하는 것이 좋다.

## 2. 제어문 (Control Statement)

제어문은 조건에 따라 코드를 다르게 실행하거나, 같은 코드를 반복 실행하고 반복을 중단할 때 사용한다.

제어문의 종류
구분	종류	목적
조건문	if, if~else, if~else if~else, switch	조건에 따라 실행
반복문	for, while, do~while	코드를 반복 실행
반복 제어문	break, continue	반복 종료 또는 다음 반복으로 이동
3. 조건문
3-1. 단일 조건문 (if)

조건식이 true일 때만 내부 코드를 실행한다.

형식

if (조건식) {
    // 조건식이 true일 때 실행
}


예제: 짝수 판별

import java.util.Scanner;

public class 단일조건문 {
    public static void main(String[] args) {
        Scanner scan = new Scanner(System.in);

        System.out.print("정수 입력: ");
        int num = scan.nextInt();

        if (num % 2 == 0) {
            System.out.println(num + "은(는) 짝수입니다.");
        }

        scan.close();
    }
}


**핵심 개념**

조건식에는 true 또는 false로 평가되는 식을 사용한다.
조건이 참이면 중괄호 안의 코드를 실행한다.
조건이 거짓이면 해당 코드를 건너뛴다.
중괄호 {}를 생략하면 바로 다음 한 문장만 조건문의 영향을 받는다.
3-2. 선택 조건문 (if~else)

조건이 참일 때와 거짓일 때 서로 다른 코드를 실행한다.

형식

if (조건식) {
    // 조건식이 true일 때
} else {
    // 조건식이 false일 때
}


예제: 짝수와 홀수 판별

import java.util.Scanner;

public class 선택조건문 {
    public static void main(String[] args) {
        Scanner scan = new Scanner(System.in);

        System.out.print("정수 입력: ");
        int num = scan.nextInt();

        if (num % 2 == 0) {
            System.out.println(num + "은(는) 짝수입니다.");
        } else {
            System.out.println(num + "은(는) 홀수입니다.");
        }

        scan.close();
    }
}

3-3. 다중 조건문 (if~else if~else)

여러 조건 중 만족하는 조건의 코드를 실행한다.

형식

if (조건식1) {
    // 조건식1이 true
} else if (조건식2) {
    // 조건식1은 false이고 조건식2가 true
} else {
    // 모든 조건이 false
}


예제: 점수에 따른 학점 판별

int score = 85;

if (score >= 90) {
    System.out.println("A학점");
} else if (score >= 80) {
    System.out.println("B학점");
} else if (score >= 70) {
    System.out.println("C학점");
} else {
    System.out.println("F학점");
}


위에서부터 조건을 검사하며, 처음으로 참이 되는 블록만 실행한다.

3-4. switch문

하나의 값에 따라 여러 실행 경로 중 하나를 선택한다.

int num = 2;

switch (num) {
    case 1:
        System.out.println("1번");
        break;
    case 2:
        System.out.println("2번");
        break;
    case 3:
        System.out.println("3번");
        break;
    default:
        System.out.println("해당 없음");
}

case: 비교할 값
break: 해당 switch 실행 종료
default: 일치하는 값이 없을 때 실행

## 4. 반복문
4-1. for문

반복 횟수가 정해져 있거나 반복 횟수를 관리하기 편리할 때 사용한다.

형식

for (초기식; 조건식; 증감식) {
    // 반복 실행할 코드
}


예제: 1부터 10까지 출력

for (int i = 1; i <= 10; i++) {
    System.out.println(i);
}


실행 순서:

초기식 실행
조건식 검사
조건이 참이면 반복문 내부 실행
증감식 실행
조건식 검사부터 반복

## 4-2. while문

조건이 참인 동안 반복 실행한다. 반복 횟수가 명확하지 않은 상황에서도 사용할 수 있다.

형식

while (조건식) {
    // 반복 실행할 코드
}


예제: 1부터 5까지 출력

int i = 1;

while (i <= 5) {
    System.out.println(i);
    i++;
}


주의: 조건식이 계속 참이면 무한 반복이 발생할 수 있으므로, 필요한 경우 반복 조건을 변경해야 한다.

4-3. do~while문

조건을 검사하기 전에 코드를 먼저 실행한다. 따라서 조건이 처음부터 거짓이어도 최소 한 번은 실행된다.

형식

do {
    // 최소 한 번 실행
} while (조건식);


예제

int i = 1;

do {
    System.out.println(i);
    i++;
} while (i <= 5);


while문과 달리 조건 검사보다 실행이 먼저 이루어진다.

## 5. 반복 제어문
5-1. break

반복문 또는 switch문을 즉시 종료한다.

for (int i = 1; i <= 10; i++) {
    if (i == 5) {
        break;
    }

    System.out.println(i);
}


출력:

1
2
3
4

5-2. continue

현재 반복에서 남은 코드를 건너뛰고 다음 반복으로 이동한다.

for (int i = 1; i <= 5; i++) {
    if (i == 3) {
        continue;
    }

    System.out.println(i);
}


출력:

1
2
4
5


차이점

break: 반복문 전체 종료
continue: 현재 반복만 건너뛰고 다음 반복 진행

## 6. 입력 처리 (Scanner)

키보드로 입력받은 값을 처리할 때 Scanner를 사용할 수 있다.

import java.util.Scanner;

Scanner scan = new Scanner(System.in);

int num = scan.nextInt();       // 정수
double d = scan.nextDouble();   // 실수
boolean b = scan.nextBoolean(); // 논리값
String s = scan.next();         // 공백 전까지 문자열
String line = scan.nextLine();  // 한 줄 문자열

scan.close();

메서드	입력 데이터
nextInt()	정수
nextDouble()	실수
nextBoolean()	true 또는 false
next()	공백 전까지 문자열
nextLine()	한 줄 전체 문자열

주의: nextInt() 다음에 nextLine()을 사용하면 남아 있는 줄바꿈 문자를 먼저 읽을 수 있다. 이 경우 중간에 nextLine()을 한 번 호출하여 줄바꿈을 처리할 수 있다.

## 7. 실습 예제: 가위바위보
요구사항
컴퓨터가 0~2 사이의 난수를 생성한다.
사용자가 0, 1, 2 중 하나를 입력한다.
0은 가위, 1은 바위, 2는 보를 의미한다.
승패 또는 무승부를 출력한다.
코드
import java.util.Scanner;

public class 가위바위보 {
    public static void main(String[] args) {
        Scanner scan = new Scanner(System.in);

        int com = (int) (Math.random() * 3);

        String[] ss = {"가위", "바위", "보"};

        System.out.print("가위(0), 바위(1), 보(2): ");
        int user = scan.nextInt();

        if (user < 0 || user > 2) {
            System.out.println("잘못된 입력입니다.");
        } else {
            System.out.println("컴퓨터: " + ss[com]);
            System.out.println("사용자: " + ss[user]);

            System.out.println("\n====== 결과 ======");

            if (com == user) {
                System.out.println("비겼습니다.");
            } else if ((user - com + 3) % 3 == 1) {
                System.out.println("사용자 승리!");
            } else {
                System.out.println("컴퓨터 승리!");
            }
        }

        scan.close();
    }
}

핵심 코드 설명
int com = (int) (Math.random() * 3);

Math.random()은 0.0 이상 1.0 미만의 실수를 반환한다.
여기에 3을 곱하면 0.0 이상 3.0 미만이 된다.
int로 변환하면 0, 1, 2 중 하나가 생성된다.
String[] ss = {"가위", "바위", "보"};


배열 인덱스를 이용해 숫자를 문자열로 변환한다.

ss[0] → 가위
ss[1] → 바위
ss[2] → 보
(user - com + 3) % 3 == 1


이 조건은 사용자가 컴퓨터보다 한 단계 이기는 경우를 판별한다.

바위는 가위를 이긴다.
보는 바위를 이긴다.
가위는 보를 이긴다.
원본 코드에서 주의할 점
System.out.println("사용자:"+ ss[com]);은 컴퓨터의 선택값을 출력하는 오류이다. ss[user]로 수정해야 한다.
if(num % 2 == 0);처럼 조건문 뒤에 세미콜론을 붙이면 빈 문장이 실행되어 조건문과 다음 블록이 분리된다.
원본 가위바위보 코드에서는 사용자 승리와 컴퓨터 승리 조건이 동일하게 출력되어 있었다. 승패 조건을 구분해야 한다.
사용자 입력은 0~2 범위인지 검사해야 배열 인덱스 오류를 방지할 수 있다.

## 8. JSP, Thymeleaf와의 차이
구분	설명
JSP	HTML 안에서 Java 기반 서버 코드를 활용하는 기술
Thymeleaf	HTML 템플릿에 서버 데이터를 연결하는 템플릿 엔진
Spring Boot	Java 기반 애플리케이션을 쉽게 구성하도록 지원하는 프레임워크

삼항 연산자는 Java에서도 사용할 수 있으며, JSP나 Thymeleaf에서도 조건에 따라 값을 표현하는 데 활용할 수 있다. 단, Thymeleaf에서는 주로 th:if, th:unless, 표현식 등을 이용해 조건부 렌더링을 처리한다.

## 9. 핵심 정리
문법	핵심 역할
if	조건이 참일 때 실행
if~else	참과 거짓에 따라 선택
if~else if~else	여러 조건 중 하나 선택
switch	값에 따라 분기
for	반복 횟수를 관리하기 편리한 반복문
while	조건이 참인 동안 반복
do~while	최소 한 번 실행 후 조건 검사
break	반복문 또는 switch 종료
continue	현재 반복을 건너뛰고 다음 반복으로 이동
?:	조건에 따라 값 선택

for, while로 반복 처리
break, continue로 반복 제어
