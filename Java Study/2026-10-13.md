# 핵심내용 정리

## 1. 자바의 동작 과정

자바는 소스 코드를 바이트 코드로 컴파일한 후 JVM(Java Virtual Machine)을 통해 실행하는 프로그래밍 언어이다.

1.1 자바 프로그램 실행 순서
A.java

   │
   
   │ javac (컴파일)
   
   ▼
   
A.class

   │
   
   │ java (실행)
   
   ▼
   
JVM

   │
   
   ▼
   
프로그램 실행 및 결과 출력

1.2 실행 단계

① 소스 코드 작성 — A.java

개발자가 작성한 자바 프로그램이다.
사람이 읽고 이해할 수 있는 형태의 코드이다.
소스 코드 또는 원시 코드라고 한다.

② 컴파일 — javac

자바 소스 코드를 바이트 코드로 변환한다.
컴파일 결과로 .class 파일이 생성된다.
javac A.java


③ 바이트 코드 생성 — A.class

JVM이 실행할 수 있는 바이트 코드가 저장된다.
운영체제와 CPU가 직접 실행하는 기계어와는 다르다.

④ 실행 — java

JVM이 바이트 코드를 실행한다.
인터프리터와 JIT 컴파일러 등을 활용한다.
java A


※ 실행 시에는 일반적으로 .class 확장자를 제외한 클래스 이름을 사용한다.

1.3 자바의 주요 명령어
명령어	기능
javac	소스 코드를 컴파일하여 클래스 파일 생성
java	자바 프로그램 실행
javap	클래스 파일의 구조와 바이트 코드 정보 확인
jar	클래스 파일과 리소스 등을 JAR 파일로 묶기

# 2. 자바 언어의 특징

2.1 재사용성 (Reusability)
이미 작성한 클래스와 메소드를 다시 사용할 수 있다.
중복 코드를 줄이고 개발 효율을 높인다.
상속이나 객체 조합 등을 통해 기능을 재사용할 수 있다.

2.2 가독성 (Readability)
변수와 메소드에 의미 있는 이름을 사용한다.
들여쓰기와 코드 정렬을 일관되게 유지한다.
주석을 사용하여 코드의 목적과 동작을 설명한다.
// 한 줄 주석

/*
 여러 줄 주석
*/

/**
 * 문서화 주석
 */

2.3 확장성 (Extensibility)
새로운 요구사항에 맞춰 기능을 추가하거나 변경하기 쉽게 설계할 수 있다.
클래스와 메소드 단위로 기능을 분리하면 확장에 유리하다.
리팩토링을 통해 기존 동작은 유지하면서 코드 구조를 개선할 수 있다.

2.4 유지보수성 (Maintainability)
코드를 이해하고 수정하기 쉽게 작성하는 특성이다.
의미 있는 변수명과 적절한 주석을 사용한다.
중복 코드를 줄이고 기능별로 코드를 분리한다.

**핵심: 재사용성, 가독성, 확장성은 프로그램의 유지보수성을 높이는 데 도움이 된다.**

# 3. 자바 프로그램 작성 시 주의사항
3.1 main() 메소드

일반적인 자바 애플리케이션은 main() 메소드에서 실행을 시작한다.

public class A {
    public static void main(String[] args) {
        System.out.println("Hello Java");
    }
}

main()은 일반적인 자바 애플리케이션의 시작점이다.
JVM은 지정된 클래스에서 실행 가능한 main() 메소드를 찾아 실행한다.
모든 자바 코드가 반드시 main()을 포함하는 것은 아니다. 라이브러리 클래스 등은 main() 없이도 작성할 수 있다.

3.2 클래스명과 파일명
public 최상위 클래스가 있다면 파일명은 해당 클래스명과 같아야 한다.
자바는 대소문자를 구분한다.
// 파일명: A.java

public class A {
    public static void main(String[] args) {
        System.out.println("Java");
    }
}

3.3 세미콜론(;)

대부분의 실행문 끝에는 세미콜론을 작성한다.

int age = 20;
System.out.println(age);


클래스와 메소드의 중괄호 뒤에는 일반적으로 세미콜론을 붙이지 않는다.

3.4 한글 사용 주의
변수명, 클래스명, 메소드명에는 영문 사용을 권장한다.
한글 식별자도 허용되지만 협업과 가독성을 위해 영문이 일반적이다.
문자열과 주석에는 한글을 사용할 수 있다.
String name = "홍길동";
System.out.println("안녕하세요");

3.5 대소문자 구분
int age = 20;
int Age = 30;


age와 Age는 서로 다른 변수이다.

# 4. 변수와 메모리
4.1 변수란?

변수(Variable)는 데이터를 저장하고 사용하기 위해 이름을 붙인 저장 공간이다.

데이터를 저장하고 읽을 때 사용한다.
변수에 저장된 값은 변경할 수 있다.
자료형에 따라 저장 가능한 값의 종류와 표현 범위가 달라진다.
int age = 20;
age = 25;

System.out.println(age); // 25

4.2 변수와 메모리의 관계
메모리 공간
┌───────────────────┐

│ 다른 데이터        │

├───────────────────┤

│ age가 참조하는 값  │ ← 변수명으로 접근

├───────────────────┤

│ 다른 데이터        │

└───────────────────┘

메모리는 프로그램 실행 중 데이터와 명령을 저장하는 공간이다.
변수명은 프로그램에서 값을 참조하기 위한 이름이다.
실제 메모리 주소와 저장 방식은 JVM과 실행 환경에서 관리된다.

4.3 메모리 종류
종류	특징	활용 예시
RAM	휘발성 메모리	실행 중인 프로그램의 데이터
ROM	비휘발성 메모리	펌웨어 저장
SSD/HDD	비휘발성 저장 장치	파일과 프로그램 저장

프로그램 종료 시 실행 중 사용하던 메모리는 회수될 수 있다. 다만 모든 메모리가 즉시 해제되는 것은 아니며, JVM의 메모리 관리 방식에 따라 달라진다.

# 5. 자바 자료형

자료형(Data Type)은 변수에 저장할 수 있는 데이터의 종류와 표현 범위를 결정한다.

자바의 자료형은 크게 기본형과 참조형으로 구분된다.

5.1 기본형 자료형 8가지
분류	자료형	크기	설명
정수형	byte	1 byte	작은 정수
정수형	short	2 bytes	짧은 정수
정수형	int	4 bytes	일반적인 정수
정수형	long	8 bytes	큰 정수
실수형	float	4 bytes	단정밀도 실수
실수형	double	8 bytes	배정밀도 실수
논리형	boolean	구현에 따라 다름	참 또는 거짓
문자형	char	2 bytes	UTF-16 코드 단위 하나

※ boolean의 크기는 자바 언어에서 고정된 바이트 수로 규정하지 않는다.

5.2 정수형
자료형	크기	값의 범위
byte	1 byte	-128 ~ 127
short	2 bytes	-32,768 ~ 32,767
int	4 bytes	-2,147,483,648 ~ 2,147,483,647
long	8 bytes	-2⁶³ ~ 2⁶³-1
byte b = 100;
short s = 1000;
int age = 20;
long population = 8000000000L;

정수 리터럴의 기본 자료형은 int이다.
long 리터럴에는 L을 붙인다.
byte와 short는 표현 범위를 벗어나는 값을 저장할 수 없다.

5.3 실수형
자료형	크기	특징
float	4 bytes	약 6~7자리 유효숫자
double	8 bytes	약 15~16자리 유효숫자
float f = 10.5f;
double d = 10.5;

실수 리터럴의 기본 자료형은 double이다.
float 리터럴에는 f 또는 F를 붙인다.
double은 일반적인 실수 계산에 널리 사용된다.
정확한 금액 계산 등에는 BigDecimal을 고려할 수 있다.

5.4 논리형

논리형은 true 또는 false를 저장한다.

boolean isStudent = true;
boolean isFinished = false;


활용 예시:

로그인 여부
회원 가입 여부
작업 완료 여부
조건 판단

5.5 문자형과 문자열
char c1 = 'A';
char c2 = '홍';

String name = "홍길동";
String grade = "A+";

char: 문자 하나를 표현하는 기본형
String: 문자열을 표현하는 참조형
문자에는 작은따옴표 ' '를 사용한다.
문자열에는 큰따옴표 " "를 사용한다.
char c = '';는 오류이다.
char c = ' ';는 공백 문자이므로 올바르다.

5.6 참조형 자료형

참조형은 객체를 참조하는 데 사용한다.

대표적인 예시:

배열(Array)
클래스(Class)
인터페이스(Interface)
문자열 String
int[] scores = {80, 90, 100};
String name = "홍길동";

# 6. 변수 선언과 초기화
6.1 기본 문법
자료형 변수명 = 초기값;


예시:

int age = 20;
double avg = 89.0;
String name = "홍길동";
boolean isStudent = true;

선언: 변수의 자료형과 이름을 지정한다.
초기화: 변수에 처음 값을 저장한다.
대입: 변수에 새로운 값을 저장한다.
int age;  // 선언
age = 20; // 초기화
age = 25; // 값 변경

6.2 성적 관리 예제
int korea = 80;
int eng = 78;
int math = 90;

int total = korea + eng + math;
double avg = total / 3.0;

System.out.println(avg);

248
82.66666666666667

6.3 변수와 상수
변수: 값을 변경할 수 있다.
상수: final을 사용하여 재대입할 수 없도록 선언한다.
int age = 20;
age = 21;

상수명은 관례적으로 대문자와 밑줄을 사용한다.

# 7. 변수명 작성 규칙
7.1 기본 규칙
영문자, 한글, 밑줄(_), 달러 기호($) 등으로 시작할 수 있다.

// int 1age = 20;      // 숫자로 시작

# 8. 숫자 표현과 형 변환
8.1 여러 진법 표현
int decimal = 10;      // 10진수
int binary = 0b1010;   // 2진수
int octal = 012;       // 8진수
int hex = 0xA;         // 16진수


위 변수에는 모두 정수 10이 저장된다.

8.2 형 변환

표현 범위가 작은 자료형에서 큰 자료형으로 변환하는 경우 자동 형 변환이 가능한 경우가 많다.

int a = 10;
long b = a; // 자동 형 변환


큰 자료형에서 작은 자료형으로 변환할 때는 명시적 형 변환이 필요할 수 있다.

long c = 10L;
int d = (int) c;


값의 범위를 벗어나면 데이터 손실이 발생할 수 있다.

8.3 리터럴 접미사
long l = 10L;
float f = 10.5f;
double d = 10.5;
boolean b = true;
char c = 'A';

long: 정수 리터럴에 L
float: 실수 리터럴에 f
double: 실수 리터럴의 기본 자료형
boolean: true 또는 false
char: 작은따옴표 안에 문자 하나

# 9. 자바 출력문

줄을 바꾸지 않고 출력한다.

System.out.print("Hello ");
System.out.print("Java");


결과:

출력 후 줄을 바꾼다.

9.3 System.out.printf()

서식 지정자를 이용하여 형식에 맞춰 출력한다.

String name = "홍길동";
int age = 20;

System.out.printf("이름: %s, 나이: %d%n", name, age);

지정자	의미
%s	문자열
%d	정수
%f	실수
%c	문자

실수의 소수점 자릿수도 지정할 수 있다.

double avg = 82.6666;
System.out.printf("%.2f%n", avg);


결과:

82.67

# 10. JDK, JRE, JVM

10.1 JVM (Java Virtual Machine)
자바 바이트 코드를 실행하는 가상 머신이다.
메모리 관리와 가비지 컬렉션 등을 담당한다.
인터프리터와 JIT 컴파일러 등을 활용해 코드를 실행한다.

10.2 JRE (Java Runtime Environment)
자바 프로그램을 실행하기 위한 환경을 의미한다.
JVM과 실행에 필요한 라이브러리 등을 포함하는 개념이다.
최신 Java에서는 JDK에 실행 환경이 함께 제공되는 경우가 일반적이다.

10.3 JDK (Java Development Kit)
자바 프로그램을 개발하기 위한 도구 모음이다.
컴파일러 javac, 실행 도구 java 등을 포함한다.
디버깅 도구와 개발용 라이브러리 등을 제공한다.

개념적인 구조:

JDK
├── 개발 도구

│   ├── javac

│   ├── java

│   ├── javap

│   └── jar

├── JVM

└── 자바 실행 라이브러리

10.4 주요 명령어
명령어	기능
javac	자바 소스 코드 컴파일
java	자바 프로그램 실행
javap	클래스 파일 구조와 바이트 코드 정보 확인
jar	클래스 파일과 리소스 등을 JAR 파일로 묶기

javap는 클래스 파일의 구조와 바이트 코드 정보를 확인하는 도구이며, 원래 소스 코드를 완전하게 복원하는 도구는 아니다.

# 12. 자바 프로그램 실습

public class Hello {
    public static void main(String[] args) {
        String name = "Java";
        int age = 20;

        System.out.println("안녕하세요!");
        System.out.println("이름: " + name);

javac Hello.java

java Hello

안녕하세요!
이름: Java

12.3 실행 과정
Hello.java에 소스 코드를 작성한다.
javac Hello.java로 컴파일한다.
Hello.class 파일이 생성된다.
java Hello 명령어로 실행한다.
JVM이 프로그램을 실행하고 결과를 출력한다.


# 13. 핵심 내용 정리
자바는 소스 코드를 바이트 코드로 컴파일한 후 JVM에서 실행한다.
javac는 컴파일, java는 프로그램 실행을 담당한다.
재사용성, 가독성, 확장성은 유지보수성 향상에 도움이 된다.
일반적인 자바 애플리케이션은 main() 메소드에서 시작한다.
public 최상위 클래스가 있다면 파일명과 클래스명이 일치해야 한다.
변수는 데이터를 저장하고 사용하기 위한 이름이 있는 저장 공간이다.
자바의 기본형은 8가지이며 String은 참조형이다.
변수는 자료형 변수명 = 값; 형식으로 선언할 수 있다.
변수명에는 숫자로 시작하거나 공백을 포함할 수 없다.
print(), println(), printf()는 출력 방식이 서로 다르다.
JDK는 개발 도구를 제공하고 JVM은 바이트 코드를 실행한다.
데이터는 메모리뿐 아니라 파일과 데이터베이스에도 저장할 수 있다.
