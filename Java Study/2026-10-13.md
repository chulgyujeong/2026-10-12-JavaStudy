1. 자바의 동작 과정

자바는 소스 코드를 바이트 코드로 컴파일한 후 JVM(Java Virtual Machine)을 통해 실행하는 언어이다.

1.1 자바 프로그램 실행 순서
A.java
   │
   │ javac (컴파일)
   ▼
A.class
   │
   │ java (실행)
   ▼
JVM에서 바이트 코드 실행
   │
   ▼
프로그램 결과 출력

1.2 실행 단계

① 소스 코드 작성 — A.java

개발자가 작성한 자바 프로그램이다.
사람이 읽고 이해할 수 있는 형태의 코드이다.
원시 코드 또는 소스 코드라고 한다.

② 컴파일 — javac

자바 소스 코드를 바이트 코드로 변환한다.
컴파일 결과로 .class 파일이 생성된다.
javac A.java


③ 바이트 코드 생성 — A.class

JVM이 실행할 수 있는 바이트 코드가 저장된다.
운영체제와 CPU가 직접 실행하는 기계어와는 다르다.

④ 실행 — java

JVM이 바이트 코드를 실행한다.
JVM은 인터프리터와 JIT 컴파일러 등을 활용해 바이트 코드를 실행한다.
java A


※ 실행할 때는 일반적으로 .class 확장자를 제외한 클래스 이름을 입력한다.

1.3 핵심 명령어

명령어	기능
javac A.java	소스 코드를 컴파일하여 클래스 파일 생성
java A	해당 클래스의 프로그램 실행

2. 자바 언어의 특징
   
2.1 재사용성 (Reusability)

이미 작성한 클래스와 메소드를 다시 사용할 수 있다.
중복 코드를 줄이고 개발 효율을 높일 수 있다.
상속과 객체 조합 등을 통해 기능을 재사용할 수 있다.

2.2 가독성 (Readability)

변수와 메소드에 의미 있는 이름을 사용한다.
들여쓰기와 코드 정렬을 일관되게 유지한다.
주석을 사용하여 코드의 목적과 동작을 설명한다.

주석 작성 예시:

// 한 줄 주석

/*
 여러 줄 주석
*/

/**
 * 문서화 주석
 */

2.3 확장성 (Extensibility)

새로운 요구사항에 맞춰 기능을 추가하거나 변경하기 쉽도록 설계할 수 있다.
클래스와 메소드 단위로 기능을 분리하면 확장에 유리하다.
리팩토링을 통해 기존 동작은 유지하면서 코드 구조를 개선할 수 있다.

2.4 유지보수성 (Maintainability)

코드를 이해하고 수정하기 쉽게 작성하는 특성이다.
의미 있는 변수명, 적절한 주석, 일관된 코드 스타일이 중요하다.
중복 코드를 줄이고 역할에 따라 기능을 분리하면 유지보수가 쉬워진다.

3. 자바 프로그램 작성 시 주의사항
   
3.1 main() 메소드

일반적인 자바 애플리케이션은 다음과 같은 시작 메소드를 사용한다.

public static void main(String[] args) {
    System.out.println("Hello Java");
}

main()은 일반적인 자바 애플리케이션의 시작점이다.
JVM은 지정된 클래스에서 적절한 진입점인 main() 메소드를 찾아 실행한다.
main()의 중괄호 { } 안에 실행할 코드를 작성한다.

3.2 클래스명과 파일명

public 최상위 클래스가 있다면 파일명은 해당 클래스명과 같아야 한다.
대소문자를 구분하므로 클래스명과 파일명을 정확히 일치시킨다.

예시:

// 파일명: A.java

public class A {
    public static void main(String[] args) {
        System.out.println("Java");
    }
}

3.3 문장 끝에는 세미콜론(;) 사용

대부분의 실행문은 세미콜론으로 끝낸다.
클래스나 메소드의 선언부 뒤에 오는 중괄호에는 세미콜론을 붙이지 않는다.
int age = 20;
System.out.println(age);

3.4 한글 사용 주의

변수명, 클래스명, 메소드명은 영문을 사용하는 것이 일반적이다.
한글 식별자도 허용되지만 협업과 가독성을 위해 영문 사용을 권장한다.
문자열이나 주석에는 한글을 사용할 수 있다.
String name = "홍길동";
System.out.println("안녕하세요");

3.5 대소문자 구분

자바는 대소문자를 구분한다.

int age = 20;
// int Age = 20;  // age와 Age는 서로 다른 변수

4. 자바 프로그램 실행 예제
   
4.1 소스 코드 작성

파일명: Hello.java

public class Hello {
    public static void main(String[] args) {
        String name = "Java";

        System.out.println("안녕하세요!");
        System.out.println(name);
    }
}

4.2 컴파일 및 실행

javac Hello.java
java Hello


실행 결과:

안녕하세요!
Java

4.3 실행 과정 정리

Hello.java 파일에 소스 코드를 작성한다.
javac Hello.java 명령어로 컴파일한다.
Hello.class 파일이 생성된다.
java Hello 명령어로 실행한다.
JVM이 프로그램을 실행하고 결과를 출력한다.

5. 핵심 내용 정리
   
자바 소스 파일의 확장자는 .java이다.
javac는 소스 코드를 바이트 코드로 컴파일한다.
컴파일 결과는 일반적으로 .class 파일이다.
JVM은 바이트 코드를 실행하며 인터프리터와 JIT 컴파일러 등을 활용한다.
일반적인 자바 애플리케이션은 main() 메소드에서 시작한다.
public 최상위 클래스의 이름과 파일명은 일치해야 한다.
대부분의 실행문 끝에는 세미콜론(;)을 사용한다.
재사용성, 가독성, 확장성, 유지보수성을 고려하여 코드를 작성한다.
