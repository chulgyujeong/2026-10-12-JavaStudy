1. 자바 학습 과정

자바는 크게 기본 문법, 객체지향 프로그래밍, 예외 처리, 라이브러리 활용 순서로 학습한다.

1.1 자바 기본 문법

프로그램의 기본 동작과 소스 코드 분석에 필요한 문법을 학습한다.

변수(Variable)
데이터 타입(Data Type)
연산자(Operator)
제어문(Control Statement)
배열(Array)

학습 목표

데이터 저장 및 관리 방법 이해
연산과 조건에 따른 프로그램 흐름 제어
배열을 이용한 여러 데이터 관리

1.2 객체지향 프로그래밍(OOP)

객체를 중심으로 프로그램을 설계하고 구현하는 방법을 학습한다.

주요 개념

클래스(Class)
객체(Object)
메소드(Method)
생성자(Constructor)
인터페이스(Interface)
추상 클래스(Abstract Class)

객체지향의 주요 특징

캡슐화(Encapsulation): 데이터와 기능을 하나로 묶어 관리
은닉화(Information Hiding): 내부 데이터를 외부에서 직접 접근하지 못하도록 제한
상속(Inheritance): 기존 클래스의 특성과 기능을 물려받음
다형성(Polymorphism): 하나의 타입으로 다양한 객체를 처리

SOLID 원칙

객체지향 설계의 유지보수성과 확장성을 높이기 위한 5가지 설계 원칙
각 원칙의 개념과 적용 방법 학습

1.3 예외 처리(Exception Handling)

프로그램 실행 중 발생하는 예외 상황을 처리하는 방법을 학습한다.

예외가 발생하더라도 적절히 처리하여 프로그램이 비정상적으로 종료되는 것을 방지
오류 상황에 대응하고 안정적인 프로그램 실행을 지원

2. 자바 프로그램의 기본 처리 순서

프로그램은 일반적으로 다음 순서로 데이터를 처리한다.

데이터 입력 및 저장
사용자가 전달한 데이터를 메모리에 저장한다.
변수(Variable)를 사용한다.
요청 처리
연산자와 제어문을 이용해 데이터를 처리한다.
필요한 기능은 메소드(Method)로 분리하여 재사용한다.
결과 출력
처리 결과를 화면이나 파일 등으로 출력한다.
입출력(I/O) 기능을 활용한다.

처리 흐름 요약

데이터 입력 → 변수에 저장 → 연산 및 제어 → 메소드 처리 → 결과 출력

3. 변수의 개념

변수(Variable)란?

메모리 공간에 이름을 붙여 데이터를 저장하고 사용하기 위한 것이다.

데이터를 저장할 때 사용한다.
변수의 데이터 타입에 따라 저장할 수 있는 값의 종류가 달라진다.
저장된 값은 프로그램 실행 중 변경될 수 있다.

예시:

int age = 20;
String name = "Java";

System.out.println(age);
System.out.println(name);

int: 정수형 데이터 타입
String: 문자열을 나타내는 클래스
age, name: 변수 이름
20, "Java": 변수에 저장된 값

4. 자바 라이브러리

자바에서 제공하는 라이브러리를 활용하면 다양한 기능을 직접 구현하지 않고 사용할 수 있다.

4.1 주요 라이브러리
분류	주요 기능	관련 API
컬렉션(Collection)	여러 데이터의 저장 및 관리	List, Set, Map
입출력(I/O)	파일 및 데이터 입출력	File, InputStream, Reader
JDBC	데이터베이스 연결 및 SQL 실행	Connection, Statement, ResultSet
스레드(Thread)	여러 작업의 동시 실행	Thread, Runnable
네트워크(Network)	네트워크 통신	Socket, ServerSocket

학습 우선순위

필수: 컬렉션, 입출력, JDBC
추가 학습: 스레드, 네트워크

※ 위 분류는 학습을 위한 정리이며, 실제 학습 순서는 과정에 따라 달라질 수 있다.

5. 예외 처리

예외 처리는 프로그램 실행 중 발생하는 예외를 감지하고 처리하는 기능이다.

주요 키워드

try: 예외가 발생할 수 있는 코드 작성
catch: 발생한 예외 처리
finally: 예외 발생 여부와 관계없이 실행할 정리 작업 작성
throw: 예외를 직접 발생시킴
throws: 메소드에서 발생할 수 있는 예외를 선언

예시:

try {
    int result = 10 / 0;
} catch (ArithmeticException e) {
    System.out.println("0으로 나눌 수 없습니다.");
}


예외를 적절히 처리하면 해당 예외로 인한 프로그램의 비정상적인 종료를 방지할 수 있다.
