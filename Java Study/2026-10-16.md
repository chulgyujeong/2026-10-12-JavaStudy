## 1. 단일 조건문 (if)

if문은 조건식이 true일 때 특정 코드를 실행하는 제어문입니다.

기본 형식
if (조건식) {
    // 조건식이 true일 때 실행
}

1.1 최대값과 최소값 구하기

학습 내용

Math.random()을 이용한 난수 생성
if문을 이용한 최대값 및 최소값 비교
int a = (int)(Math.random() * 100) + 1;
int b = (int)(Math.random() * 100) + 1;
int c = (int)(Math.random() * 100) + 1;

System.out.printf("a=%d, b=%d, c=%d%n", a, b, c);

int max = a;
if (max < b)
    max = b;
if (max < c)
    max = c;

System.out.println("최대값: " + max);

int min = a;
if (min > b)
    min = b;
if (min > c)
    min = c;

System.out.println("최소값: " + min);


**핵심 개념**

(int)(Math.random() * 100) + 1 : 1부터 100까지의 정수 생성
max에 가장 큰 값을 저장
min에 가장 작은 값을 저장
여러 조건을 순서대로 검사하여 최댓값과 최솟값 결정

1.2 사용자 입력에 따라 웹사이트 열기

학습 내용

Scanner를 이용한 정수 입력
if문으로 메뉴 선택
Runtime.getRuntime().exec()를 이용한 외부 프로그램 실행
입력값	실행할 웹사이트
1	Google
2	Naver
3	Daum
Scanner scan = new Scanner(System.in);

System.out.print("정수 입력: ");
int num = scan.nextInt();

if (num == 1) {
    // Google 실행
} else if (num == 2) {
    // Naver 실행
} else if (num == 3) {
    // Daum 실행
} else {
    System.out.println("잘못된 입력입니다.");
}


실제 웹사이트 실행 코드는 운영체제에 설치된 브라우저 경로에 따라 달라집니다. 기존 실습에서는 Windows의 Chrome 실행 파일 경로를 사용했습니다.

1.3 사칙연산 계산기

학습 내용

정수와 연산자 입력
charAt(0)으로 첫 번째 문자 추출
연산자별 조건 처리
0으로 나누는 경우 예외 처리
Scanner scan = new Scanner(System.in);

System.out.print("첫 번째 정수 입력: ");
int num1 = scan.nextInt();

System.out.print("두 번째 정수 입력: ");
int num2 = scan.nextInt();

System.out.print("연산자 입력 (+, -, *, /, %): ");
char op = scan.next().charAt(0);

if (op == '+') {
    System.out.println(num1 + num2);
}
if (op == '-') {
    System.out.println(num1 - num2);
}
if (op == '*') {
    System.out.println(num1 * num2);
}
if (op == '/') {
    if (num2 == 0) {
        System.out.println("0으로 나눌 수 없습니다.");
    } else {
        System.out.println(num1 / (double) num2);
    }
}
if (op == '%') {
    if (num2 == 0) {
        System.out.println("0으로 나눌 수 없습니다.");
    } else {
        System.out.println(num1 % num2);
    }
}


**핵심 개념**

scan.next() : 문자열 입력
charAt(0) : 문자열의 첫 번째 문자를 추출
num1 / (double) num2 : 정수 나눗셈이 아닌 실수 나눗셈 수행
num2 == 0 : 0으로 나누는 상황 방지

1.4 문자 종류 판별

학습 내용

문자 비교
논리 연산자 &&, ||
대문자, 소문자, 숫자, 기타 문자 구분
Scanner scan = new Scanner(System.in);

System.out.print("문자 입력: ");
char c = scan.next().charAt(0);

if (c >= 'A' && c <= 'Z') {
    System.out.println("대문자입니다.");
}
if (c >= 'a' && c <= 'z') {
    System.out.println("소문자입니다.");
}
if (c >= '0' && c <= '9') {
    System.out.println("숫자입니다.");
}
if (!((c >= 'A' && c <= 'Z')
   || (c >= 'a' && c <= 'z')
   || (c >= '0' && c <= '9'))) {
    System.out.println("기타 문자입니다.");
}


논리 연산자

연산자	의미	예시
&&	AND, 두 조건이 모두 참	num >= 1 && num <= 10
`		`
!	NOT, 조건의 반대	!(num == 1)
1.5 가위바위보 게임

학습 내용

난수로 컴퓨터의 선택 결정
배열을 이용한 문자열 관리
사용자와 컴퓨터의 결과 비교
Scanner scan = new Scanner(System.in);

int com = (int)(Math.random() * 3);

System.out.print("가위(0), 바위(1), 보(2): ");
int user = scan.nextInt();

String[] ss = {"가위", "바위", "보"};

System.out.println("컴퓨터: " + ss[com]);
System.out.println("사용자: " + ss[user]);

if (com == user) {
    System.out.println("비겼습니다.");
} else if ((user - com + 3) % 3 == 1) {
    System.out.println("사용자 승리!");
} else {
    System.out.println("컴퓨터 승리!");
}


**핵심 개념**

Math.random() * 3 : 0부터 2까지의 정수 생성
String[] : 가위, 바위, 보를 배열에 저장
(user - com + 3) % 3 == 1 : 사용자가 이기는 경우 판별

입력값이 0, 1, 2 범위를 벗어나지 않도록 검증하면 더욱 안전합니다.

## 2. 선택문 (switch)

switch문은 변수나 표현식의 값에 따라 여러 경우 중 하나를 선택하여 실행하는 제어문입니다.

기본 형식
switch (변수) {
    case 값1:
        // 실행문
        break;
    case 값2:
        // 실행문
        break;
    default:
        // 일치하는 값이 없을 때
}


Java 14 이상에서는 화살표 형식의 switch도 사용할 수 있습니다.

switch (num) {
    case 1 -> System.out.println("1번");
    case 2 -> System.out.println("2번");
    default -> System.out.println("기타");
}

2.1 월별 계절 판별

학습 내용

월에 따라 계절 구분
여러 case를 묶어서 처리
default를 이용한 잘못된 입력 처리
switch (month) {
    case 12, 1, 2 -> System.out.println("겨울");
    case 3, 4, 5 -> System.out.println("봄");
    case 6, 7, 8 -> System.out.println("여름");
    case 9, 10, 11 -> System.out.println("가을");
    default -> System.out.println("잘못된 월입니다.");
}

2.2 switch를 이용한 계산기

학습 내용

문자열 연산자로 계산 방식 선택
중첩 switch를 이용한 0 나누기 검사
default로 잘못된 연산자 처리
Scanner scan = new Scanner(System.in);

System.out.print("첫 번째 정수: ");
int num1 = scan.nextInt();

System.out.print("두 번째 정수: ");
int num2 = scan.nextInt();

System.out.print("연산자 (+, -, *, /): ");
String op = scan.next();

switch (op) {
    case "+" -> System.out.println(num1 + num2);
    case "-" -> System.out.println(num1 - num2);
    case "*" -> System.out.println(num1 * num2);
    case "/" -> {
        if (num2 == 0) {
            System.out.println("0으로 나눌 수 없습니다.");
        } else {
            System.out.println(num1 / (double) num2);
        }
    }
    default -> System.out.println("잘못된 연산자입니다.");
}


if와 switch 비교

구분	if문	switch문
조건	범위 및 복합 조건	특정 값에 따른 분기
사용 예시	점수, 나이, 범위 비교	메뉴, 연산자, 월 선택
기본 구조	if, else if, else	case, default

## 3. 선택 조건문 (if-else)

if-else문은 조건이 참일 때와 거짓일 때 서로 다른 코드를 실행합니다.

기본 형식
if (조건식) {
    // 조건이 true일 때
} else {
    // 조건이 false일 때
}

3.1 홀수와 짝수 판별
int a = 11;

if (a % 2 == 0) {
    System.out.println(a + "은 짝수입니다.");
} else {
    System.out.println(a + "은 홀수입니다.");
}


핵심 개념

a % 2 == 0 : 짝수
a % 2 != 0 : 홀수
else는 앞의 if 조건이 거짓일 때 실행
3.2 성적 계산 및 합격 판정

학습 내용

국어, 영어, 수학 점수 입력
총점과 평균 계산
평균 60점 이상이면 합격 처리
Scanner scan = new Scanner(System.in);

System.out.print("국어 점수: ");
int kor = scan.nextInt();

System.out.print("영어 점수: ");
int eng = scan.nextInt();

System.out.print("수학 점수: ");
int math = scan.nextInt();

int total = kor + eng + math;
double avg = total / 3.0;

System.out.println("총점: " + total);
System.out.printf("평균: %.2f%n", avg);

if (avg >= 60) {
    System.out.println("합격!");
} else {
    System.out.println("불합격!");
}


주의 사항

total / 3처럼 정수끼리 나누면 소수점 이하가 버려집니다. 정확한 평균을 구하려면 total / 3.0 또는 total / 3.0과 같은 실수 연산을 사용합니다.

3.3 대문자와 소문자 판별

학습 내용

난수로 알파벳 종류 선택
문자형 char 활용
if-else로 두 가지 결과 구분
int type = (int)(Math.random() * 2);
char c;

if (type == 0) {
    c = (char)((Math.random() * 26) + 65);
} else {
    c = (char)((Math.random() * 26) + 97);
}

if (c >= 'A' && c <= 'Z') {
    System.out.println(c + "는 대문자입니다.");
} else {
    System.out.println(c + "는 소문자입니다.");
}

대문자 ASCII 코드 범위: 65~90
소문자 ASCII 코드 범위: 97~122
알파벳 26개 중 하나를 무작위로 선택

## 4. 삼항 연산자

삼항 연산자는 조건에 따라 두 값 중 하나를 선택하는 간결한 표현식입니다.

기본 형식
조건식 ? 참일 때 값 : 거짓일 때 값;

예제
int a = 10;

String result = (a % 2 == 0) ? "짝수" : "홀수";

System.out.println(result);


출력 결과

짝수


if-else로 표현할 수 있는 간단한 조건을 한 줄로 작성할 때 유용합니다.

## 5. 반복문

반복문은 조건에 따라 같은 코드를 여러 번 실행할 때 사용합니다.

5.1 do-while문

do-while문은 조건을 검사하기 전에 코드를 먼저 실행합니다. 따라서 조건이 처음부터 거짓이어도 최소 한 번은 실행됩니다.

int i = 1;

do {
    System.out.println(i);
    i++;
} while (i <= 5);


출력 결과

1
2
3
4
5


실행 순서

반복문 본문 실행
i++로 값 증가
i <= 5 조건 검사
조건이 참이면 반복, 거짓이면 종료
5.2 중첩 for문으로 별 출력

학습 내용

for문 사용
중첩 반복문
print()와 println()의 차이
for (int i = 1; i <= 4; i++) {
    for (int j = 1; j <= i; j++) {
        System.out.print("*");
    }
    System.out.println();
}


출력 결과

*
**
***
****

바깥쪽 for문: 별을 출력할 행의 개수 결정
안쪽 for문: 각 행에 출력할 별의 개수 결정
System.out.print() : 줄바꿈 없이 출력
System.out.println() : 출력 후 줄바꿈

## 6. 핵심 문법 정리

문법	설명	대표 예시

if	조건이 참일 때 실행	if (num > 0)

if-else	참과 거짓을 구분	if (num % 2 == 0)

else if	여러 조건을 순서대로 검사	점수별 등급

switch	특정 값에 따라 분기	메뉴 선택

&&	모든 조건이 참이어야 함	num >= 1 && num <= 10

`		`

!	조건 반전	!(num == 1)

%	나머지 연산	num % 2 == 0

Math.random()	0.0 이상 1.0 미만 난수	(int)(Math.random() * 100) + 1

Scanner	사용자 입력 처리	scan.nextInt()

charAt(0)	첫 번째 문자 추출	scan.next().charAt(0)

삼항 연산자	조건에 따른 값 선택	조건 ? 값1 : 값2

do-while	본문을 먼저 실행하는 반복문	do { ... } while (조건);

중첩 for	반복문 안에 반복문 작성	별 출력
반복문을 활용하여 원하는 형태의 출력을 만듭니다.

사용 기술: Java · Scanner · Math.random() · 조건문 · 선택문 · 삼항 연산자 · 반복문
