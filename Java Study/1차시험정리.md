# 핵심 개념 정리

1. 자바 실행 과정

Hello.java
    ↓ javac 컴파일러
Hello.class (바이트코드)
    ↓ JVM
인터프리터 / JIT 컴파일러
    ↓
운영체제와 CPU에서 실행

javac: 소스 코드를 바이트코드로 컴파일한다.
JVM: 바이트코드를 실행하는 가상 머신이다.
인터프리터: 바이트코드를 해석하여 실행한다.
JIT 컴파일러: 자주 실행되는 코드를 기계어로 컴파일하여 성능을 높인다.

2. 식별자 작성 규칙

식별자는 변수명, 클래스명, 메소드명 등에 사용하는 이름이다.

숫자로 시작할 수 없다.
문자, _, $ 등으로 시작할 수 있다.
숫자를 포함할 수 있다.
대소문자를 구분한다.
공백을 포함할 수 없다.
자바 키워드를 식별자로 사용할 수 없다.
명명 규칙
대상	일반적인 규칙	예시
변수	camelCase	userName
메소드	camelCase	getName()
클래스	PascalCase	StudentInfo
상수	대문자와 _	MAX_SIZE

위 명명 규칙은 일반적인 관례이며, 식별자의 문법적 허용 여부와는 구분해야 한다.

4. 변수와 초기화

변수의 종류
인스턴스 변수: 객체에 속하는 변수
정적 변수(static): 클래스에 속하는 변수
지역변수: 메소드나 블록 내부에서 선언하는 변수
매개변수: 메소드 호출 시 전달되는 값을 받는 변수
기본 초기화 규칙
인스턴스 변수와 정적 변수는 기본값으로 자동 초기화된다.
지역변수는 사용 전에 반드시 값이 할당되어야 한다.
final 변수는 초기화한 후 재할당할 수 없다.
class Student {
    int age;                  // 기본값 0
    static String schoolName; // 기본값 null

    void printAge() {
        int num = 10;         // 지역변수는 직접 초기화
        System.out.println(num);
    }
}

5. 연산자 우선순위

일반적으로 다음 순서로 우선순위를 이해하면 된다. 단, 정확한 순위는 연산자 종류에 따라 달라진다.

괄호 ()
단항 연산자 ++, --, !, 단항 +, 단항 -
산술 연산자 *, /, %, +, -
비교 및 동등 연산자 <, >, <=, >=, ==, !=
논리 AND &&
논리 OR ||
삼항 연산자 ?:
대입 연산자 =, +=, -=

예제:

int result = 5 + 3 * 2;

System.out.println(result); // 11


곱셈이 덧셈보다 우선하므로 3 * 2를 먼저 계산한다.

6. 전위와 후위 증감 연산자
int a = 10;
int b = a++;

System.out.println(b); // 10
System.out.println(a); // 11

++a: 값을 먼저 증가시킨 후 해당 표현식에서 사용한다.
a++: 해당 표현식에서는 기존 값을 사용하고 증가한다.

7. 자동 형변환과 명시적 형변환

자동 형변환

표현 가능한 범위와 정밀도 등을 고려하여 안전하게 변환할 수 있는 경우 자동 형변환이 가능하다.

int num = 10;
double result = num;

명시적 형변환
double d = 3.14;
int num = (int) d;

System.out.println(num); // 3


실수에서 정수로 변환하면 소수 부분이 버려진다.

8. 단축 평가

&&와 ||는 조건 결과가 확정되면 뒤의 조건을 평가하지 않는다.

int a = 10;
int b = 9;

boolean result = a < 5 && ++b == 10;

System.out.println(result); // false
System.out.println(b);      // 9


첫 번째 조건이 false이므로 ++b는 실행되지 않는다.

&&: 첫 번째 조건이 false이면 뒤를 평가하지 않는다.
||: 첫 번째 조건이 true이면 뒤를 평가하지 않는다.

9. 문자열 결합

System.out.println("Hello" + " Java");
// Hello Java

System.out.println("Java" + 10);
// Java10

System.out.println("Java" + 10 + 1);
// Java101

System.out.println(10 + 1 + "Java");
// 11Java


문자열 결합과 산술 연산은 같은 + 기호를 사용하므로 연산 순서를 주의해야 한다.

10. 비트 연산자와 논리 연산자

연산자	종류	설명
&&	논리 AND	단축 평가 지원
`		`
!	논리 NOT	논리값 반전
&	비트 AND / 논리 AND	논리값에 사용할 때 양쪽 모두 평가
`	`	비트 OR / 논리 OR
^	비트 XOR / 논리 XOR	서로 다를 때 참 또는 비트 비교
~	비트 NOT	비트 반전

11. 복합 대입 연산자

int a = 10;

a += 3; // a = 13
a -= 2; // a = 11
a *= 2; // a = 22
a /= 2; // a = 11
a %= 3; // a = 2


복합 대입 연산자는 일반적인 연산보다 현저히 느리다고 볼 수 없다. 또한 a += 3은 a = a + 3과 비슷하지만, 복합 대입 연산자는 결과를 왼쪽 변수 타입으로 변환하는 효과가 있어 모든 상황에서 완전히 동일한 것은 아니다.

12. 상수 (final)

final int MAX_SIZE = 100;

// MAX_SIZE = 200; // 컴파일 오류


final은 변수에 재할당을 허용하지 않도록 한다. 참조형 변수에 final을 적용하면 참조 자체를 다른 객체로 바꿀 수 없지만, 참조 대상 객체의 상태까지 반드시 변경 불가능해지는 것은 아니다.

기본형과 참조형의 차이를 이해한다.
지역변수와 인스턴스 변수의 초기화 규칙을 안다.
연산자 우선순위를 적용할 수 있다.
전위와 후위 증감 연산자의 차이를 이해한다.
자동 형변환과 명시적 형변환을 구분할 수 있다.
&&와 ||의 단축 평가를 이해한다.
문자열 결합과 비트 연산자의 동작을 설명할 수 있다.
final과 복합 대입 연산자의 특징을 이해한다.
